# Noir Analytics

> On-chain analytics dashboard in dark theme

## Features

- Whale tracking
- Volume analysis
- Wallet profiler
- Market signals

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Blockchain: Solidity, Rust, Web3.js
- AI: MiMo V2 Flash, Claude Code

## Installation

```bash
git clone https://github.com/mupoiyu/noir-analytics.git
cd noir-analytics
npm install
npm run dev
```
